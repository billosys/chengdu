# cpddl

**cpddl** is a small library for parsing PDDL and grounding of the PDDL input to a
STRIPS representation.

## Compile And Install

Easiest way to compile the library and the binaries that come with the
library:
```
  $ make boruvka opts
  $ make
  $ make -C bin
```
