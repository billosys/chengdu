## Ledger Notes

- The goal is not to make dependency code warning-clean. The goal is to prove
  the grounder first-party gates exclude dependency code unless a later audit
  accepts that boundary.
- Do not let `rss.c` remain ambiguous. It must be either first-party warning
  debt or explicitly documented as copied/dependency-internal source with
  selectors and re-entry updated to match.
- Unit/seam evidence must exercise maintained grounder logic directly. A
  managed process fixture wrapper is useful regression evidence but is not a
  unit test.
