## Ledger Notes

- `build/source-quality/<platform>/` is generated output and should remain
  ignored; it is evidence, not committed source.
- Raw compile databases may include generated or dependency translation units
  required by the actual build. The closure criterion is that first-party
  selector/filter evidence exists beside the raw compile database and excludes
  those paths for future gates.
- If compile database generation for parser or grounder cannot be achieved
  without a larger build-system rewrite, do not close the row as deferred.
  Request a slice amendment.
- Do not use this slice to enforce coverage floors, warning budgets, or
  parser/grounder/engine static-analysis findings. Slice03 owns the gate
  scaffold and threshold posture.
