## Ledger Notes

- The naming policy is scoped to first-party maintained C/C++ source and source
  directories. It does not rename vendored third-party/dependency-internal
  paths or generated/build outputs.
- The check target should be deterministic and suitable for later inclusion in
  first-party source-quality gates.
- Use `git mv` for renames. On macOS, case-only renames should use a temporary
  intermediate name when required so Git records the rename correctly.
- If the rename set is too large to fit one context with verification
  headroom, stop and request a split rather than partially normalizing a
  component and calling the row done.
