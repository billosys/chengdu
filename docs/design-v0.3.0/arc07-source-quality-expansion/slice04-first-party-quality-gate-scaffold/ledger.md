## Ledger Notes

- Scaffold targets are allowed to be report-only when the report has concrete
  evidence and re-entry conditions. They are not allowed to be empty green
  targets.
- Later component burndown slices should convert report-only rows into
  executable gates or release-blocking policies one component at a time.
- Generated-warning triage is deliberately first-class: the warning text is
  not enough; the root cause and semantic correctness question must be
  answered before closure.
