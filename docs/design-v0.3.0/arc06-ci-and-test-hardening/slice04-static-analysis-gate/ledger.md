## What Good Looks Like

- The static-analysis target is easy to find from `make help`.
- The first meaningful signal is owned runtime/process-policy code, not a wall
  of unclassified inherited planner findings.
- Missing tools and deferred analyzer/adoption-seam scopes are named with
  concrete re-entry conditions.
