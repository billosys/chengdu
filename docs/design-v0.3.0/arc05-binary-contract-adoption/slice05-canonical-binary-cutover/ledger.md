## Notes

- This slice supersedes earlier parser/grounder inherited-name compatibility
  expectations for active 0.3.0 surfaces. Historical closed reports should not
  be rewritten unless they are explicitly promoted into current instructions.
- "No shim" means no distributable parser/grounder artifact depends on
  `pandaPIparser`, `pandaPIgrounder`, or a `.legacy` sidecar to satisfy the
  0.3.0 managed-process contract.
- New GitHub Actions / CI jobs must invoke make targets, not project scripts.
