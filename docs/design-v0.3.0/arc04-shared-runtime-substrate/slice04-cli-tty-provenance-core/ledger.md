## What Worked

The slice stayed inert at the binary boundary while still making the Arc03
policy testable in `pandapi::runtime`. Splitting the work into `cli_policy`,
`tty`, and `provenance` kept public types focused, let the seam test exercise
all behavior without CLI11 or shell TTY state, and preserved the later Arc05
adoption boundary.
