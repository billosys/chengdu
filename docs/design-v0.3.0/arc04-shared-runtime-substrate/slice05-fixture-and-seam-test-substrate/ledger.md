## What Worked

- Keeping fixture vocabulary, process observation, and normalization as
  separate runtime headers made the criteria checks direct without coupling the
  new substrate to parser, grounder, or engine.
- The assert-based smoke test covers the required default behavior without a
  vendored test framework, while the optional Catch2 target proves the seam can
  use a local Catch2 installation when present.
- Re-running the row-level shell probes exposed invalid no-diff checks in F-16
  and F-18. Correcting those Verify commands made the ledger executable without
  weakening the protected-path criteria.
