## What Worked

- Keeping the status taxonomy in `status.cpp` keeps public headers
  declaration-only while still exposing strongly typed C++ vocabulary.
- A plain C++ seam test was sufficient to prove all accepted status names,
  classes, exit codes, signal mapping, and `StatusResult<T>` behavior without
  importing Catch2 before its owning slice.
- Representing `signal_terminated` as `ProcessStatus::signal_terminated()`
  keeps supervisor-observed signal death dynamic and avoids treating it as a
  fixed ordinary exit code.
