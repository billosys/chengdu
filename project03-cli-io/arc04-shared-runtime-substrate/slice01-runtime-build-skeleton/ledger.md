## What Worked

- Keeping the runtime as a standalone static CMake target avoided coupling
  existing Makefile/CMake planner builds to the new substrate.
- A plain executable smoke test kept slice01 standard-library-only and avoided
  importing Catch2 before the slice that owns test-framework adoption.
- Building into ignored `build/runtime/$PLATFORM` matched existing generated
  output hygiene without placing artifacts under `pandapi-runtime/`.
- Documentation can name future dependency gates while source/build checks
  remain scoped to actual import surfaces.
